**核心项目背景（群内反复出现）：**
- **PEYT Chat（peytchat）**：基于 **Delta Chat**（端到端、去中心化聊天工具，需翻墙、用海外服务器）深度定制的工作室版，强调端到端加密、自主可控、可自部署。技术栈桌面端 **Rust core + Tauri**，另起 Android 端（MaherJon）。
- **团队社区 / 协作系统（PleaseEnterYourTextCommunity）**：以团队 workspace 为核心的协作社区，用 Tauri+json-rpc 与 Rust core 通信，实现 IM 聊天、bot 层、文件管理、内置 GUI git 操作、群组/频道等。
- 仓库：组织 `github.com/PleaseEnterYourText-Studio`；主仓库 `github.com/NoWint/PleaseEnterYourTextCommunity`（含 `PeytchatAndroid` 分支）；文档站 `nowint.github.io/PeytDocs`；已有线上部署 `peyt.yzjtiantian.cn`。

## 三、主要话题 / 讨论主题

### 1. 项目开发与架构（主旋律）
- **团队社区/协作系统方案**：诺温特。提出基于 DeltaChat Desktop Tauri 版改前端、扩展数据层，「直接使用 core 的优势是方便设计桌面 app 前端和扩充 rust 后端」，社区以团队 workspace 为核心，同时实现 im 聊天、bot 层、文件管理、内置 GUI git 操作。
- **PEYT Chat 功能迭代**：做群组与频道（被反复催：「做群组和频道」）、自建邀请链接协议（desktop 端短链接邀请功能、自建邀请协议默认样式）、聊天消息 MD 渲染是否开开关、页面指引文案「写可爱点，营造非正式氛围」。
- **协作系统缺口**：「协作系统缺人干啊」「桌面端似乎还需要助手」；协作系统定调「只能依赖群聊或者包装成频道」。

## 七、对工作室的启示

1. **真实规模很小**：核心干活者只有 5~6 人（NoWint、TiantianYZJ.、Carry-Rao、ieshishinjin、MaherJon、Falswqwq），其余多为互动/审核/测试角色；前两名贡献了六成发言。
2. **产品处于「可通信的内测」阶段**：PEYT Chat 已能编译、能通信、有线上部署和邀请链接，但正式版、官网、对外宣传 08-08 才真正起步；协作系统、群组频道、Android 端均「缺人干」。
3. **招人难、流失快**：审核标准（答辩式、记录时长、GitHub 沉淀）在 12 天内快速迭代成型；「新人流失率有点高」「月抛月出幻觉」是被反复提及的痛点。
4. **AI 深度嵌入**：从 bot（astrbot/golang）、Claude Code、opencode 到「把 IM 包装成 AI provider」的网关构想，再到用 AI 分析群聊写文案——AI 是工作室日常开发与运营的底座。
5. **自主可控是内核动机**：因为 Delta Chat 需翻墙、依赖海外服务器，才自研端到端加密的 PEYT Chat；「加密且自主可控」构成对外叙事的主轴。
6. **管理决策偏随性**：群名「乱起」、官网反复易手、宣发渠道摇摆（B站→抖音→推特），靠的是高活跃与强个人关系维系，制度化沉淀（官网/公告/固定流程）仍在建设中。
